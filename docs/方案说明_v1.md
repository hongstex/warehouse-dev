## 方案对比
| | 方案 B 东西向通长（推荐） | 方案 A 南北向短排 |
|---|---|---|
| 仓位（格×2 层） | 388 | 384 |
| 可存布卷 | 6,208~9,700 | 6,144~9,600 |
| 作业通道 / 主通道 | 2.3m / 2.65m | 2.0m（柱位处 1.7m）/ 3.0m |
| 小叉车 | 可进作业通道（低速） | 基本只能走主通道 |
| 货架段数 | 38 | 70 |
| 钢材净重（全 80×80×3 主材） | 约 44.3t | 约 48.1t |
| 与 7 楼一致 | 是 | 否 |

**推荐 B 的理由：** 仓位略多，通道能走叉车，钢材更省、段数少（安装量小），作业习惯和 7 楼一致。

**B 的代价：** 南北墙各有一排靠墙货架，会挡住下部窗户；货架排较长，靠 4 处横向过道分段。

### 方案 B 断面（自南向北）
南墙单排 1.95 → 通道 2.3 → 双排 4.0（含 3-B 轴柱）→ 通道 2.3 → 单排 1.95（两面可取）→ 主通道 2.65 → 双排 4.0（含 3-C 轴柱）→ 通道 2.3 → 北墙单排 1.95。合计 23.4m。

- 3-B、3-C 轴的柱子落在双排里，每 8m 柱距放 3 格，柱位那一格空着，不占通道。
- 横向过道共 4 处，都是空出一格宽：西端、东端各一处，3-4 和 3-10 轴附近各一处（避开消火栓）。另外，3-7 轴卷帘带同时作为过道。

## 每格容量与荷载
- 单格：沿排方向 2.0m（净 1.92m）× 进深 1.95m × 2 层。
- 一层承货面标高 0.15m，二层 2.0m，立柱高 3.8m。
- 每格每层可放：
  - 40cm 布卷：4×4 = 16 卷；
  - 35cm 布卷：5×5 = 25 卷，但二层梁需上调到约 2.1m，货顶约 3.9m。
- 荷载：每格最多约 1.5t，货架投影下约 3.8 kN/m²，全层平均约 1 kN/m²。

## 货架构造（螺栓连接，不烧焊）
- **立柱：** 80×80×3，正面和侧面按 50mm 间距冲 φ11 孔，层高可调。
- **侧片：** 每列前后两根立柱，用三道横撑（一层、二层、柱顶，80×80×3）加两道斜撑（40×40×2）组成。
- **承货：**
  - 每层前后各一根承货梁（80×80×3），加两根中间托梁（60×40×2）。
  - 布卷卷轴朝进深方向，140 幅宽的布卷也至少搭在两根梁上。
- **连接：**
  - 梁端用 L75×75×6 冲孔角码，配 M10 螺栓 4 套。
  - 方管内建议加套管，防止拧紧时压扁管壁。
- **稳定：**
  - 背面每 4 格设一道剪刀撑。
  - 背靠背两排在中部和顶部用短管拉结。
- **地脚：** 底板 150×150×8，每柱 2 个 M12 机械锚栓。打孔深度要控制，并避开楼板内管线。

## 风险 / 需复核
1. **梁底与喷头净空：** 立柱按 3.8m 计，梁底可能只有约 3.6m，需现场实测。
2. **楼面活荷载：** 需查结构设计说明。
3. **螺栓货架稳定性：** 先做一段样架，试装、试载。
4. **叉车余量：** 带 1.8m 布卷在 2.3m 通道里行驶，余量约每边 25cm，需低速；转弯在主通道或横向过道进行。
5. **消防：** 丙类厂房改作仓储可能涉及使用功能变更；卷帘下方和疏散通道不得堆货。
6. **读图估计项：** 核心筒、门位、消火栓位置需现场复核。
