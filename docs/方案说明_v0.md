# 面料仓货架布置草稿 v0

底图：宝日汽车综合服务产业园 3#楼《二~七层平面图》J-4改（1:150）。
图纸：`public/files/layout_v0.png` / `.pdf`；可导入 CAD 的 `public/files/layout_v0.dxf`（单位 mm，原点为 3-1×3-A 轴交点，图层已分）。
生成脚本：`layout/generate.py`（参数改完重新运行即可出图）；排布优化：`layout/optimize_rows.py`。

## 1. 楼层条件（读图所得）
- 外轮廓 96m × 24m，柱网 8m × 8m（12 跨 × 3 跨），层高 4.3m，标准层建筑面积 2311 m²。
- 两个防火分区，以 3-7 轴防火卷帘分隔（3-A~3-C 段，耐火极限不低于 3h）：西区 1090 m²，东区 1221 m²。
- 核心筒：T1（3-1~3-2/3-C~3-D，含货梯）、T2（3-5~3-7 北侧，楼梯 + 卫生间）、T3（3-12~3-13/3-C~3-D，含货梯）。货梯只有两端各一部。
- 原设计的“卸货平台”位于 3-2~3-3 南北两侧和 3-12~3-13 南侧，外墙上设有 JM1a 门。
- 厂房按丙类、耐火等级二级设计，设自动喷淋。

## 2. 布置思路
| 项目 | 取值 | 理由 |
|---|---|---|
| 货架排向 | 南北向（垂直于长边） | 通道尽端正对外窗，不挡采光、通风和排烟窗；单条通道短（约 10m），拣货路线短 |
| 布卷方向 | 卷轴垂直于通道 | 与 7 楼一致，从端头推入取出 |
| 单格 | 沿通道 2.0m × 进深 1.95m × 2 层 | 沿用 7 楼 2m 模数；进深 1.95m 可放 180 幅宽布卷 |
| 双排（背靠背） | 4.0m（1.95 + 0.1 + 1.95） | |
| 作业通道 | 2.0m，局部 2.3~3.7m | 沿用 7 楼 2m 通道 |
| 主通道 | 东西向居中，3.0m | 连接两端货梯，可容两车交会 |
| 防火卷帘 | 卷帘线两侧各留 1m，共 2m 净空带 | 带内不放货物，可兼作两侧货架的通道 |

- 柱子处理：8m 柱距与 6m 的“双排 + 通道”模数不一致。用程序优化排位后，大部分柱子落在货架内（占掉 1 格）；3-3、3-4、3-10、3-11 轴的柱子有约 0.3m 凸入通道，这 4 根轴线所在通道在柱位处净宽缩到 1.7m（每条通道 2 处）。
- 东区按西区以 3-7 轴镜像布置，两边规格统一，便于编码管理。
- 功能区：
  - 两部货梯出口处各设收发暂存区，约 80 m² 和 75 m²。
  - 东区卫生间旁设验布/分拣/待上架区，约 45 m²。
  - T2 前室门前保留通道。
  - 消火栓箱、烟道前方不布置货架。

## 3. 指标（v0）
- 单格（每层）203 个 × 2 层 = **406 个仓位**（西区 194 / 东区 212）。
- 货架占地约 792 m²，扣除核心筒后可用面积约 1997 m²，占地率约 40%。
- 按每格每层约 36 卷（φ≈0.3m）、25kg/卷估算：每格约 1.8t，货架投影下荷载约 4.6 kN/m²，全层平均约 1.8 kN/m²。

## 4. 风险/需复核
1. **梁底与喷头净空**：层高 4.3m，8m 跨主梁高度约 0.6~0.7m，梁底净高可能只有约 3.6m。货顶还需与喷头溅水盘保持规范净距，“2 层 × 2m、货顶 4m”在梁下和喷头下可能不成立，需现场实测，或与 7 楼做法对照。
2. **楼面活荷载**：需查结构设计说明，确认楼面活荷载 ≥ 上述货架投影荷载。
3. **使用性质**：丙类厂房改作面料仓储，需确认是否涉及消防使用功能变更。货物不得占用疏散通道和卷帘下方。
4. 核心筒尺寸、门位、消火栓位置均为读图估计，需现场复核。
